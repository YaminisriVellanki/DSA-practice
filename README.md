## 🧩 Problem-Solving Approach

For each problem, I aim to understand:

1. Problem statement
2. Examples and edge cases
3. Brute-force approach
4. Optimized approach
5. Data structure or algorithm used
6. Time complexity
7. Space complexity
8. Final implementation

My focus is on **understanding the logic rather than memorizing solutions**.
